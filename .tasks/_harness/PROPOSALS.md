# Harness proposals — queue

Written by `harness-improver` (proposals only, never applied automatically). The operator grooms this
queue periodically: recurring patterns become real skill/rule changes; one-offs are pruned; declined ideas
move to **Rejected** and are off the table.

Upstream vs local: if a proposal targets a skill installed from `~/.config/ai-tooling`, decide whether the
fix belongs **upstream** (edit the canonical copy there, then re-install into every project) or **local**
(this repo only — note that the next install will overwrite it unless the skill is marked local).
